COMPUTER FUNDAMENTALS

Computer Parts & Their Uses

Computer की basic से advanced जानकारी

🧠

CPU

CPU का पूरा नाम Central Processing Unit है। यह computer की instructions को process करता है। इसके मुख्य parts ALU, CU और Registers हैं।

⚡

RAM

RAM का पूरा नाम Random Access Memory है। यह temporary memory है जिसमें currently running programs और data रखा जाता है।

💾

ROM

ROM का पूरा नाम Read Only Memory है। इसमें जरूरी permanent instructions store रहती हैं।

💽

Hard Disk / SSD

HDD और SSD permanent data storage के लिए उपयोग होते हैं। SSD सामान्यतः HDD से तेज होती है।

⌨️

Keyboard

Keyboard एक input device है जिसका उपयोग text, numbers और commands enter करने के लिए होता है।

🖱️

Mouse

Mouse एक pointing input device है। इससे click, select, drag और navigation किया जाता है।

🖥️

Monitor

Monitor एक output device है जो computer की information को screen पर दिखाता है।

🖨️

Printer

Printer digital document को paper पर print करने के लिए उपयोग किया जाता है।

🌐

Internet

Internet दुनिया भर के computers और networks को connect करने वाला global network है।

👨‍🔬

Charles Babbage

Charles Babbage ने Difference Engine और Analytical Engine की concepts पर काम किया। उन्हें computer history में महत्वपूर्ण योगदान के लिए जाना जाता है।
