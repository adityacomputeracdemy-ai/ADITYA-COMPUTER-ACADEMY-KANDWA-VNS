Computer Parts & Uses

Computer Fundamentals — A to Z

Students के लिए आसान language में notes और visual learning.

🧠 CPU — Central Processing Unit

CPU computer का processing centre है। यह instructions को fetch, decode और execute करता है। इसके मुख्य parts ALU, CU और registers हैं.

⚡ RAM & ROM

RAM temporary working memory है, जबकि ROM non-volatile memory है जिसमें जरूरी startup instructions stored रहते हैं.

💾 Storage

HDD/SSD data को long-term store करते हैं। SSD सामान्यतः faster और silent storage technology है.

⌨️ Input Devices

Keyboard, mouse, scanner, microphone, webcam आदि user से data/instructions लेते हैं.

🖥️ Output Devices

Monitor, printer, speaker और projector processed information को user तक पहुँचाते हैं.

🌐 Internet

Internet interconnected networks का global system है। Browser, search engine, email, cloud और online services इसके common uses हैं.

👨‍💻 Charles Babbage

Charles Babbage ने Difference Engine और Analytical Engine की concepts पर काम किया। Analytical Engine को modern general-purpose computer की दिशा में एक महत्वपूर्ण ऐतिहासिक कदम माना जाता है.

🕰️ Computer Generations

1st: Vacuum Tubes • 2nd: Transistors • 3rd: Integrated Circuits • 4th: Microprocessors • 5th: AI/advanced computing technologies.

🔐 Cyber Safety

Strong passwords, 2FA, software updates, backups और suspicious links से सावधानी basic digital safety practices हैं.
